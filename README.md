# ГринБокс — Веб-студия

🎁 **Макет за 24 часа бесплатно**

Современный сайт веб-студии по созданию интернет-магазинов с профессиональным дизайном, анимациями и полным функционалом.

## 🌐 Демо

**Действующий сайт:** [greenboxweb.ru](https://greenboxweb.ru/)

## ✨ Особенности

- **Современный дизайн** — минималистичный интерфейс с анимациями
- **Адаптивная верстка** — корректно работает на всех устройствах  
- **Темная/светлая тема** — автоматическое переключение
- **Анимации на Canvas** — интерактивные частицы на главной
- **Многошаговый бриф** — удобная форма для клиентов
- **Telegram интеграция** — уведомления о заявках
- **SEO оптимизация** — правильная структура и мета-теги

## 🛠 Технологии

- **Vite** — современный сборщик
- **Vanilla JavaScript** — без фреймворков
- **CSS Custom Properties** — система дизайна  
- **Canvas API** — анимации частиц
- **Intersection Observer** — анимации на скролл
- **Telegram Bot API** — уведомления

## 📁 Структура проекта

```
greenbox/
```

## 🚀 Быстрый старт

### Для просмотра
Откройте `index.html` в браузере или разместите файлы на веб-сервере.

### Для разработки

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/TarrySeeker/GreenBox.git
   cd GreenBox
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите dev-сервер:**
   ```bash
   npm run dev
   ```

4. **Сборка для продакшена:**
   ```bash
   npm run build
   ```

## 🎨 Дизайн-система

### Цвета
- **Primary:** `#00C853` (зеленый)
- **Primary Hover:** `#00E676`
- **Background:** `#FAFBFC` (светлая) / `#0A0A14` (темная)
- **Text:** `#1A1A2E` (светлая) / `#E8E8F0` (темная)

### Типографика
- **Основной шрифт:** Inter
- **Заголовки:** Space Grotesk
- **Размеры:** от 0.75rem до 4.5rem

### Анимации
- **Частицы Canvas** — интерактивный фон
- **Scroll animations** — появление блоков
- **Hover эффекты** — карточки и кнопки
- **Тема переключение** — плавные переходы

## 📱 Адаптивность

- **Desktop:** 1200px+
- **Tablet:** 768px - 1199px  
- **Mobile:** 320px - 767px

## 🔧 Кастомизация

### Изменение цветов
Отредактируйте CSS переменные в `:root` секции:

```css
:root {
  --color-primary: #00C853;
  --color-primary-hover: #00E676;
  /* ... другие цвета */
}
```
